# Google Cloud MCP access and cost boundaries

Check Google's current docs before execution: [configure an MCP AI application](https://docs.cloud.google.com/mcp/configure-mcp-ai-application), [authenticate](https://docs.cloud.google.com/mcp/authenticate-mcp), [prevent read-write MCP tool use](https://docs.cloud.google.com/mcp/prevent-read-write-tool-use), and [budget limitation](https://cloud.google.com/billing/docs/how-to/disable-billing-with-notifications).

- Google Cloud remote MCP uses Streamable HTTP endpoints per supported product/toolset, not one universal Cloud Console endpoint. The target project must have the product API enabled; doing so is an authorized change requiring `serviceusage.services.enable` and may affect cost/exposure. MCP calls need `mcp.tools.call` (for example via `roles/mcp.toolUser`) **plus** service-specific permissions. Discover the exact products and resource boundaries before choosing URLs and roles.
- Google's MCP IAM deny conditions can use `mcp.googleapis.com/tool.isReadOnly`, but their limitations matter: checks apply to `mcp.tools.call`, not generic REST/CLI permissions; some attribute combinations are restricted, and Resource Manager has an exception. Treat an MCP tool filter as one layer, never as a complete write/cost firewall.
- Authentication can use Google ADC, OAuth client credentials, or an authorization header, but a copied bearer token expires and an owner's ADC carries their permissions. Select a refreshable dedicated identity and verify Hermes' actual auth support and credential scope before configuring. Avoid service-account JSON keys where keyless federation or another reviewed short-lived method is viable.
- Google Cloud budget notifications arrive after some costs accrue; even automatically disabling billing after an alert cannot guarantee staying under the threshold and may terminate services. Do not call a budget alert a hard cap. BigQuery queries and changes to existing resources can be charged without creating a new project or VM.
- Read-only does not mean insensitive or free: project metadata, logs, datasets, and secret *metadata* can expose private information, while some reads incur usage charges. Explicitly decide which resources the agent needs; verify pricing, API state, and IAM effects before a bounded list/get smoke test. For an initial project-only pilot, avoid broad `roles/viewer`, log/data/billing permissions and project IAM-policy reads; assess the exact custom role or predefined `roles/browser` permissions before any binding.
- On a non-Google host, Workload Identity Federation needs a real attested issuer; a one-time personal browser login does not create a workload identity. Google Cloud Resource Manager MCP has exceptions to generic MCP `tool.isReadOnly` controls, and an OAuth-backed Hermes MCP flow may require a pre-registered client plus refresh-token handling. Verify the actual client/server compatibility and token refresh before recommending MCP instead of a constrained API adapter.
